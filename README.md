# ドローポーカー

ブラウザで遊べる5枚ドローポーカーです。CPU 3人と対戦します。
ビルドもサーバーも不要で、`index.html` をブラウザで開くだけで遊べます。

## ハンドの流れ

1. 5枚ずつ配られる
2. 全員が参加料（アンティ）を支払う
3. 1回目のベット（チェック／ベット／コール／レイズ／フォールド）
4. カード交換：好きな枚数（0〜5枚）を1回だけ交換
5. 2回目のベット
6. ショーダウン：残った人の中で役がいちばん強い人がポットを獲得
7. ハンドの終わりには、フォールドした人も含めて全員の手札を公開（1人を残して全員が降りた場合も同じ）

## 操作

- **フォールド**（`F`）／**チェック・コール**（`C`）／**ベット・レイズ**（`R`）
- ベット額はスライダーか入力欄で決める。「1/2 ポット」「ポット」「オールイン」で素早く設定
- カード交換では、交換したいカードをタップして選び「n枚交換する」を押す（キーボード: `1`〜`5` で選択、`Enter` で決定）

## ルール

- 持ち点 1000、参加料 10 から開始。10ハンドごとに参加料が倍になります
- ベット・レイズの最小単位は参加料の2倍
- あなたのチップがなくなるとゲームオーバー、CPU 全員のチップを奪えば優勝
- オールイン時のサイドポット、引き分け時のポット分割に対応

## CPU の思考

交換後の手の勝率をモンテカルロ法で見積もり、ポットオッズと比べてコール／レイズ／フォールドを決めます。
交換はペアを残す・4枚フラッシュ／ストレートを狙うなどの定石どおり。交換しなかった相手は強いとみなして警戒します。
CPU ごとに攻撃性・ルーズさが異なり、ときどきブラフもします。

## ファイル構成

## シャッフルの公平性

山札は Fisher–Yates 法でシャッフルし、乱数にはブラウザの暗号用乱数 `crypto.getRandomValues` を使っています。
実際の配札処理を大量に回してカイ二乗検定で偏りを調べるスクリプトがあります。

```sh
node scripts/check-randomness.js 500000
```

各席に配られるカード、役の出る割合（理論値との比較）、交換で引くカードの偏りを検査します。
