# テキサスホールデム

ブラウザで遊べるテキサスホールデム・ポーカーです。CPU 3人と対戦します。
ビルドもサーバーも不要で、`index.html` をブラウザで開くだけで遊べます。

## 遊び方

1. `index.html` をブラウザで開く
2. 「ゲーム開始」を押す
3. 自分の番になったら行動を選ぶ
   - **フォールド** … 降りる（キーボード: `F`）
   - **チェック / コール** … 賭けずに回す / 相手の賭け額に合わせる（`C`）
   - **ベット / レイズ** … スライダーか入力欄で額を決めて賭ける（`R`）
   - 「1/2 ポット」「ポット」「オールイン」で額をすばやく設定
4. ハンドが終わったら「次のハンドへ」

## ルール

- 持ち点 1000、ブラインド 10/20 から開始。10ハンドごとにブラインドが倍になります
- あなたのチップがなくなるとゲームオーバー、CPU 全員のチップを奪えば優勝です
- オールイン時のサイドポット、引き分け時のポット分割に対応しています

## CPU の思考

モンテカルロ法で自分の手の勝率を見積もり、ポットオッズと比べてコール／レイズ／フォールドを決めます。
CPU ごとに攻撃性・ルーズさが異なり、ときどきブラフもします。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html`, `style.css` | 画面 |
| `js/evaluator.js` | カード・役判定・勝率計算 |
| `js/engine.js` | ゲーム進行（ベッティング、ポット、ショーダウン、CPU） |
| `js/ui.js` | 描画と操作 |
| `test/poker.test.js` | テスト |
